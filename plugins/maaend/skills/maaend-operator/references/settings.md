# 配置更新与回读

先读取所选实例的当前快照和目录依据，确认要改的既有条目。版本化快照与脱敏查看视图不同；未展示、被过滤或被遮蔽的内容不能当成不存在，也不能用于重建整份配置。

当前有限更新针对一个实例内已有条目的顺序、启停及声明允许的安全选项。调整完整顺序时保留全部原条目和身份；只改启停或某项选项时保留其他内容。不能新造任务、改其他实例、控制器路径、执行程序或宿主声明。

提交同时绑定本次目录和保存配置的版本依据。目录或配置冲突时重新读取最新内容，保留其他客户端的改动后再决定变更；不重交旧请求。只读回退可用于查看，但不能作为无版本保存或运行的依据。

密码、路径、预执行程序、辅助组件声明、原始流程和计划等限制不能通过未知字段或改磁盘文件绕过。正常热键也须符合当前声明及安全结构，不能把输入值当成命令。

保存响应丢失时，已有回读证据只能说明可能应用了哪些内容，不足以宣布全部保存成功。先只读核实，禁止自动重发；成功回读才按实际保存值说明结果，并与游戏内生效分开。
