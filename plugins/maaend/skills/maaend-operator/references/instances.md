# 实例与任务对象

实例关联自己的控制器、资源、执行器和保存配置。宿主框架已初始化、某个控制器已连通、资源已加载及执行器可用需要分别确认，不能从全局状态正常推出每个实例都就绪。

任务声明是业务定义；选中条目是实例中保存的一次选择，带有自己的顺序、启停与选项；执行记录是某次提交后的运行身份。三者的标识不能互换，选中条目身份也不能从任务名称或界面位置推算。

同一声明可以在列表中出现多次。定位时结合实例、条目、顺序和选项等当前信息，只有必要歧义无法自行解除时才询问。用户要求改一条就保留其余重名条目，不合并、不删除或改变其他项。

运行入口面向已有、启用且适用的选中任务。目录命中但未绑定到实例时，应核对当前能力是否允许管理选择项；没有新增或绑定能力就指出这个缺口，不能直接执行声明中的原始入口来绕过。

实例数量不等于独立游戏窗口或设备数量。多个实例可能共享实际控制目标或资源，未经契约确认不能并发。不能为修改选项切换整个实例环境，也不在状态查询中擅自初始化控制器或资源。
