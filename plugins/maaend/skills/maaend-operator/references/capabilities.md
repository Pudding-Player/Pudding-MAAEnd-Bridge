# 能力发现与覆盖

任务目录来自当前宿主的实时声明，配置快照描述已保存的实例和选中项，运行状态来自执行环境。它们回答不同问题，不能用目录命中推断已选中、已准备好或已经完成。

当前桥主要管理现有实例的声明查询、保存配置的有限更新和既有任务运行，不是图形宿主全部页面或底层框架函数的通用代理。源码中存在构造器、维护接口或前端特有任务，不代表桥已经开放。

已有候选时先读其条目、资源和控制器要求及选项定义。目录失败、查询范围不全、任务未加入实例、条目停用、版本不兼容和桥未覆盖分别报告；不以相近名称或第一条重名记录替代目标。

后端能提供普通配置读取，不一定支持版本化快照。缺少必要快照时可能仍可查看，但保存和依赖现有配置的任务提交不能降级为无版本操作；这是当前后端或适配链路的限制，不是软件没有对应任务。

未知选项类型、特殊前端内置行为或只有加密值而没有受支持取值方式的任务，须按桥返回的范围处理。不能解密猜测、用空值代替、另造原始流程或调用任意命令来拼出表面兼容。

需要解释实现时可读取已授权的对应版本资料；没有源码读取能力就不能假称已经检索。离线声明不能替代运行中宿主的登记和实例条件，也不产生安装、连接或执行权限。

遇到本轮常规目录或接口已经证实的覆盖缺口、契约变化或不可用时，才按需读取[缺口补足](gaps.md)。这不是正常操作的前置步骤。
