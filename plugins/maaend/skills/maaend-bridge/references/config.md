# 配置含义与生效

任务声明提供选项定义和默认值，实例配置保存用户的选择，执行状态描述本次任务正在做什么。这三层不能互相替代；声明默认不证明用户当前采用默认值，保存值也不能证明正在执行的任务已经使用它。

任务自身、通用声明、资源与控制器可能共同提供选项。选择分支还可能引入嵌套选项；不要将它们拍平成一组无条件开关，也不把另一个控制器或资源下的取值套进来。

改某个实例时，只处理其已有条目的顺序、启停和声明允许的选项；完整重排、单项修改、其他实例与共享声明的影响分别核对。未展示、被过滤或被遮蔽的内容不能当作空值重建。

版本化快照、普通只读回退和可安全保存是不同能力。能查看配置不证明当前后端支持版本化写入；缺少所需快照时，不为运行或修改偷偷降级为无版本请求。

保存核验、下次生成执行参数和游戏里的实际效果分别说明。用户只要求解释或配置时不启动任务；具体选项的含义、单位、依赖和热键规则见 maaend-operator 的选项资料。
