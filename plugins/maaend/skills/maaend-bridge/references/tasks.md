# 任务与实例

任务声明说明宿主提供哪些业务入口、入口需要什么资源和控制器，以及可配置哪些选项。它不等于用户已经把任务加入某个实例，也不证明该实例当前已经连接或准备完成。

一个实例保存自己的选中任务、顺序、启停及选项，同时关联实际执行环境。实例清单中的记录不是独立进程或设备已在线的证明；全局宿主可达，也不代表每个实例都能执行。

声明中的同一任务可以在实例里出现多次，各次有不同的条目身份、位置和选项。用户指向某一条时，按当前保存对象进一步定位，不能只凭任务名称选第一条或把重名条目合并。

当前运行入口使用已经选择且适用的任务。声明有任务但没有加入当前实例、条目被停用、资源或控制器不适配，应分别报告；不能因目录命中就承诺能立即运行，也不通过临时拼接底层流程绕过选择与兼容检查。

具体定位和执行读取 maaend-operator 的实例、选项及执行资料。声明任务身份、选中条目身份与某次运行的执行记录身份要分开，不从历史回执复制成新请求。
