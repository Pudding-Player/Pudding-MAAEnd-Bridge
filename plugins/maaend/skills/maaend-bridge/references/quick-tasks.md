# 快捷入口与编排

只封装已有实例中的现成选中条目及保存选项，不把声明目录中的一个名字当成已经配置好的执行对象。保存前核对实例、条目身份、启停与适用资源，重复名称要定位到用户要的那一条。

绑定稳定对象，执行时再按现行协议读取目录与配置版本；不把上次执行记录、临时版本或运行状态固化为以后使用的参数。只保存入口时不创建执行环境、不准备辅助组件，也不试跑游戏任务。

组合任务保持用户顺序、重复项和间隔。某个实例内的任务顺序是宿主配置，多个 Pudding 入口之间的顺序属于外层编排；不能改写整个宿主任务列表来伪装一项临时组合。

“完成后再继续”需要每项业务的真实完成证据。后台接纳和一组执行记录只证明提交被接下，不能满足等待条件；当前绑定无法表达等待、结果传递或运行时准备时，应指出具体缺口，不能靠固定时长补齐。

多个实例不默认并发。先核对它们是否共享控制目标、资源或执行限制，只有当前契约明确互不影响时才并发。保存、发布与运行分别核实；失效目标不能换成同名的另一个条目或实例。
